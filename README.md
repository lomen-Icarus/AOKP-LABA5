# Лабораторная работа №5: освещение и материалы (Rust / Bevy 0.19)

Четыре тора освещены одним точечным источником. У каждого свой материал,
параметры которого читаются из текстового файла в `assets/materials`.
Управление камерой и FPS в заголовке окна — из лабораторной №4.

## Запуск

Запускать из папки проекта: пути к файлам материалов относительные.

```
cargo run --locked
```

| Клавиша | Действие |
|---|---|
| ← / → | Поворот камеры вокруг центра |
| ↑ / ↓ | Подъём и опускание камеры |
| + / − | Приближение и удаление |

## Материалы

| Файл | Вид |
|---|---|
| `red_glossy.txt` | красный глянцевый |
| `blue_matte.txt` | синий матовый |
| `green_satin.txt` | зелёный полуматовый |
| `white_emissive.txt` | белый со слабым самосвечением |

Строка файла: имя параметра и числа через пробел (`diffuse`, `specular`,
`emission` — четыре числа, `shininess` — одно); `#` — комментарий.
После правки файла достаточно перезапустить программу.

## Модули

| Файл | Назначение |
|---|---|
| `src/main.rs` | Окно, ресурсы, системы, загрузка материалов, сцена |
| `src/data.rs` | Начальные позиции камеры и света, файлы материалов, размещение торов |
| `src/light.rs` | Ресурс `SceneLight` и система `apply_light` |
| `src/phong_material.rs` | Материал Фонга: загрузка из файла и перевод в `StandardMaterial` |
| `src/graphic_object.rs` | Графический объект со ссылкой на материал |
| `src/display.rs` | FPS в заголовке окна |
| `src/camera.rs`, `src/simulation.rs` | Камера и управление из лабораторной №4 |

Отчёт: `docs/otchet_lab05.docx`. Разбор для защиты: `docs/razbor_lab05.md`.
